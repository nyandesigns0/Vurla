# Vurla design system

## Foundations
Vurla is light-only: paper is the default surface, graphite canvas provides deliberate contrast, and mineral is a supporting field. Geist leads all typography. The brand’s hard edges are intentional; controls use square corners and clear one-pixel borders.

## Layout and spacing
Use a responsive shell capped at 80rem. Internal spacing uses the 4/12/24/40/64 scale. Keep reading measures narrow and visual grids spacious.

## Typography
Use Geist Sans for display and body roles, with high contrast, compact tracking, and no decorative serif substitute.

## Components
Buttons, fields, cards, and notices use paper/canvas surfaces, one-pixel structural borders, visible focus rings, and 44px interactive targets. Navigation is always an anchor; in-place actions are buttons.

## Motion and accessibility
Motion is restrained and may use opacity or short transforms only. Reduced-motion preferences remove nonessential movement. Every keyboard control has a visible focus indication.

## Do and don't
Do use graphite, paper, mineral, and Vurla brand marks consistently. Do use inverse marks only on graphite. Do not add a selectable dark theme, broad radius overrides, glow, or ungoverned hard-coded component colors.
